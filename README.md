## Introducción

Esta documentación explica cómo instalar **Discord** en una computadora con Windows de forma clara, ordenada y profesional.

El objetivo de esta guía es que cualquier persona pueda descargar, instalar y configurar Discord correctamente, aunque no tenga mucha experiencia instalando programas.

Discord es una herramienta muy utilizada para comunicarse por mensajes, llamadas de voz, videollamadas y servidores de comunidad.

---

## ¿Qué es Discord?

**Discord** es una aplicación de comunicación que permite hablar con otras personas mediante texto, voz y video. También permite crear servidores, canales, grupos y comunidades.

Discord se utiliza para:

- Hablar con amigos.
- Crear grupos de estudio.
- Organizar comunidades.
- Comunicarse en videojuegos.
- Hacer llamadas de voz.
- Compartir pantalla.
- Enviar archivos e imágenes.

Discord puede usarse desde el navegador, pero instalar la aplicación en Windows permite una experiencia más rápida y estable.

---

## Requisitos antes de instalar

Antes de instalar Discord, necesitas tener:

- Una computadora con Windows.
- Conexión a internet.
- Un navegador web.
- Espacio disponible en el disco.
- Un correo electrónico activo.
- Permisos para instalar programas.
- Una cuenta de Discord o disponibilidad para crear una.

---

## Requisitos del sistema

| Requisito | Recomendación |
|---|---|
| **Sistema operativo** | Windows 10 o Windows 11 |
| **Procesador** | Procesador moderno de 64 bits |
| **Memoria RAM** | 4 GB o más |
| **Espacio en disco** | 300 MB libres aproximadamente |
| **Internet** | Conexión estable |
| **Cuenta** | Correo electrónico activo |

> **Recomendación:** descarga Discord únicamente desde su sitio oficial para evitar archivos falsos o inseguros.

---

## Paso 1 — Entrar al sitio oficial

Para comenzar la instalación, abre tu navegador web.

Puedes usar:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Brave

Luego entra al sitio oficial de Discord:

[https://discord.com/download](https://discord.com/download)

![Página oficial de Discord](./imagenes/paso1-pagina-discord.png)

---

## Paso 2 — Descargar Discord

En la página oficial de descarga, busca el botón que diga:

**Download for Windows**  
o  
**Descargar para Windows**

Después de presionarlo, se descargará un archivo llamado aproximadamente:

```text
DiscordSetup.exe
```

Normalmente este archivo se guarda en la carpeta **Descargas** de Windows.

![Botón de descarga de Discord](./imagenes/paso2-boton-descarga.png)

---

## Paso 3 — Buscar el archivo descargado

Cuando termine la descarga:

1. Abre la carpeta **Descargas**.
2. Busca el archivo `DiscordSetup.exe`.
3. Verifica que el archivo tenga el nombre correcto.
4. No descargues instaladores desde páginas desconocidas.

![Archivo descargado](./imagenes/paso3-archivo-descargado.png)

---

## Paso 4 — Ejecutar el instalador

Para iniciar la instalación:

1. Haz doble clic sobre `DiscordSetup.exe`.
2. Si Windows solicita permisos, presiona **Sí**.
3. Espera a que el instalador prepare los archivos.
4. No cierres la ventana hasta que termine el proceso.

![Ejecutar instalador](./imagenes/paso4-ejecutar-instalador.png)

---

## Paso 5 — Esperar la instalación

La instalación de Discord suele ser automática. Durante este proceso:

- No apagues la computadora.
- No cierres el instalador.
- Mantén la conexión a internet activa.
- Espera hasta que Discord abra automáticamente.

![Instalación en proceso](./imagenes/paso5-instalacion.png)

---

## Paso 6 — Iniciar sesión o crear una cuenta

Cuando Discord se abra, aparecerán dos opciones principales.

### Opción 1: Iniciar sesión

Usa esta opción si ya tienes una cuenta de Discord.

Necesitarás:

- Correo electrónico o número de teléfono.
- Contraseña.

### Opción 2: Crear una cuenta

Usa esta opción si todavía no tienes cuenta.

Necesitarás:

- Correo electrónico.
- Nombre de usuario.
- Contraseña segura.
- Fecha de nacimiento.

Después de crear la cuenta, Discord puede pedirte verificar tu correo electrónico.

![Inicio de sesión](./imagenes/paso6-inicio-sesion.png)

---

## Paso 7 — Configuración inicial recomendada

Después de instalar Discord, es recomendable hacer algunas configuraciones básicas.

![Configuración inicial de Discord](./imagenes/paso7-configuracion.png)

### Cambiar el idioma

1. Abre Discord.
2. Entra en **Ajustes de usuario**.
3. Busca la opción **Idioma**.
4. Selecciona **Español**.

### Configurar notificaciones

También puedes configurar:

- Sonidos de notificación.
- Mensajes emergentes.
- Notificaciones por servidor.
- Privacidad de mensajes directos.

## Tabla de problemas comunes

| Problema | Posible causa | Solución |
|---|---|---|
| Discord no se descarga | Problema con el navegador | Intenta usar otro navegador |
| El instalador no abre | Falta permiso de administrador | Ejecuta el archivo como administrador |
| Discord se queda cargando | Internet inestable | Reinicia el router o prueba otra conexión |
| No funciona el micrófono | Dispositivo incorrecto seleccionado | Revisa la configuración de voz y video |
| No llegan notificaciones | Notificaciones desactivadas | Revisa los ajustes de notificaciones |
| No puedo iniciar sesión | Correo o contraseña incorrectos | Restablece la contraseña |
| Installation has failed | Archivos anteriores dañados | Cierra procesos de Discord y reinstala |

Este código representa una verificación sencilla antes de instalar Discord:

```python
internet_estable = True

    print("La computadora está lista para instalar Discord.")
else:
    print("Revisa los requisitos antes de instalar Discord.")
```
